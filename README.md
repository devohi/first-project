# First project

A Node.js project written in TypeScript.

## Tech stack

- Node.js
- TypeScript
- npm
- dotenv

## Setup

Requires [Node.js](https://nodejs.org/) and npm.

```bash
npm install
```

Create a `.env` file in the project root for environment variables. `dotenv` is already installed.

## Scripts

```bash
npm test
```

Application scripts will be added when the TypeScript source is set up.
