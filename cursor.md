# First project

This is AM's first Cursor workspace. Treat this folder as the project root.

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Package manager:** npm
- **Module system:** ES modules (`"type": "module"`)

Use TypeScript for all application code. Do not add JavaScript source files (`.js` / `.mjs`) unless a tool requires them. Prefer the Node.js built-in APIs and standard library before adding extra packages.

## How to work here

- Write and change code directly in this folder.
- Prefer small, working files over large scaffolding.
- Do not add extra docs, configs, or folders unless they are needed for the task.
- Do not create git commits unless AM asks.

## Conventions

- Keep names simple and descriptive.
- Use TypeScript types and interfaces; avoid `any` unless there is no better option.
- Match the language and style of existing files once they exist.
- Explain changes in plain language.

## Notes

Update this file when the project stack, folders, or team rules change.
